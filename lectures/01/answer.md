## 宿題

- 取り組んだレベル：基礎
- やったこと：
  同じ質問「LoRAとは何ですか？」に対して、次の2通りの条件で実行した。
  1. temperature を 0.0 / 1.0 / 2.0 に変えて3回（モデルは gemini-3.5-flash-lite 固定）。
     temperature は `generate_content` の `config` に `types.GenerateContentConfig(temperature=...)` を渡して指定し、`--temperature` 引数で切り替えられるよう `app/ask.py` を改修した（ブランチ temperature-experiment）。
  2. `AIE_MODEL` 環境変数でモデルを変えて実行（gemini-3.5-flash-lite / gemini-3.5-flash / gemini-3.5 / gemini-3.1-flash-lite）。

- 結果：

  ■ temperature を変えた場合（gemini-3.5-flash-lite、入力トークン数はいずれも 7）

  | temperature | 出力トークン数 | 構成 | 例え |
  |---|---|---|---|
  | 0.0 | 492 | 従来の課題 / 仕組み / 3大メリット / まとめ | 小さなノート |
  | 1.0 | 652 | 従来との違い / 3大メリット / 使われ方 / まとめ | 辞書と付箋 |
  | 2.0 | 535 | 従来の問題点 / 仕組み / メリット / 現在の使われ方 | 付箋 |

  - 3回とも「Low-Rank Adaptation の略」「本体は固定し小さな追加パラメータだけ学習」「ファイルが数MB〜」「着せ替えが簡単」という骨子は共通だった。
  - 見出しの立て方・例え・文の順序は毎回変わった。temperature 2.0 でも文章が崩れることはなかった。
  - 出力トークン数は 492 → 652 → 535 で、temperature を上げても単調に増減はしなかった。

  ■ モデルを変えた場合（入力トークン数はいずれも 7）

  | 指定した AIE_MODEL | 実際の model_version | 出力トークン数 | 備考 |
  |---|---|---|---|
  | （未指定＝既定値 gemini-3.5-flash-lite） | gemini-3.5-flash-lite | 582 | |
  | gemini-3.5-flash | gemini-3.6-flash | 821 | 指定と実際が異なる |
  | gemini-3.5 | （エラー） | — | 404: モデルが見つからない |
  | gemini-3.1-flash-lite | gemini-3.1-flash-lite | 745 | |

  - gemini-3.6-flash（指定は 3.5-flash）の回答だけが「2021年に Microsoft の研究者が提案」という出典情報と「透明シートを重ねる」という例えを含んでいた。
  - gemini-3.1-flash-lite は「学習対象パラメータが全体の 0.1%〜1% 以下」「配布サイト Civitai」など、他より具体的な数値・固有名詞を挙げた。
  - 出力トークン数は flash-lite 系（492〜652）より flash（821）が多かった。

- 気づき・疑問：
  - 【事実】temperature を 0〜2 で変えても、回答の中身（骨子）はほぼ同じで、変わるのは構成や言い回しだった。temperature 0.0 で何度も実行して完全に同一になるかは未確認。
  - 【事実】temperature と回答の長さ（出力トークン数）に単純な関係は見られなかった。ただし各1回ずつの結果なので、ばらつきの範囲内かもしれない。
  - 【事実】`AIE_MODEL=gemini-3.5-flash` と指定したのに `model_version` は gemini-3.6-flash だった。
    【推測】gemini-3.5-flash が「Flash 系の最新版」を指す別名として扱われ、その実体が 3.6 に差し替わっているのではないか。実験で条件を固定するには、`model` だけでなく `model_version` も記録しておく必要がある。
  - 【事実】`gemini-3.5` のように版の種類（flash など）を省くと 404 になった。モデル名は正確に指定する必要がある。
  - 【疑問】出力トークン数の差（492〜821）は temperature やモデルの違いによるものか、単なる実行ごとのばらつきなのか。同じ条件で複数回実行しないと切り分けられない（発展レベルの課題につながる）。
  - 【疑問】モデル名の別名がどの実体を指すかはどこで確認できるのか（Google のモデル一覧ページで確認予定）。
